    Virtual Computer Labs

    Azure Virtual Desktop (AVD) is a virtual computer lab that allows you to access software commonly required for your courses at no cost. 

    All undergraduate and graduate students currently registered for Laurier courses have access to AVD.

    AVD User Device Access Requirements

    Internet connectivity needs to support at least 40mbps downstream and 5 mbps upstream.

    AVD can be accessed by the following two platforms:

    1. Microsoft Remote Desktop client application available on Windows Store or the AppStore for Mac
      • The Microsoft Remote Desktop client application allows for additional capabilities such as full screen, port redirection and multiple monitors.
    2. Navigate to labapps.wlu.ca on any modern HTML-5 compatible web browser (Edge, Chrome, Safari, FireFox). 

    Set Up AVD on Your Personal Device

    1. Go to labapps.wlu.ca.
    2. Log in using your Laurier username and password.
    3. In the Windows Virtual Desktop Remote App Portal, double click the AZWD-LAB icon.

      Note: It may take longer to load the AVD full desktop your first time using it.
    4. In the Access local resources prompt, select Allow.
    5. Enter your username and password (without the @mylaurier.ca suffix).

    Set Up Your OneDrive

    We do not recommend storing data on your AVD profile because they are not backed up and are removed at the end of each semester. Instead, use your OneDrive folder to save and open documents/data files, making them easily accessible each time you log in.

    The first time you run AVD, you will need to initialize your OneDrive, which will provide you access to files storage: 

    1.  Double click the OneDrive icon and sign in.
       
      Or, you can use the shortcut on the desktop to set up OneDrive.

    Access OneDrive Files

    To access your OneDrive files outside of AVD: 

    1. Go to onedrive.live.com. 
    2. Log in with your Laurier username and password.

    Running AVD in Full Screen Mode 

    If you would like the application to run full screen instead of in your browser window, download the desktop application to connect to AVD.

    Windows

    1. Go to aka.ms/wvdclient
    2. The Remote Desktop msi will download to your computer (check bottom left of your window).
    3. Double click to run the setup wizard, click through all prompts.
    4. At the Let’s get started screen, subscribe rdweb.wvd.microsoft.com/api/arm/feeddiscovery
    5. Log in with your Laurier account and password.

    Mac

    1. Launch the App Store and search for "Microsoft remote desktop" or use the following link: apps.apple.com/ca/app/microsoft-remote-desktop/id1295203466?mt=12
    2. Add workspace
    3. Log in with your Laurier account and password.
