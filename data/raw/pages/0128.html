    Register for Courses

    With all the prep work you've done, you're now ready to register for your courses!

    On this page, you'll find information on: 

    • how to log in to LORIS

    • waitlist

    • overload forms

    Resources: 

    • LORIS errors and glossary

    Log In to LORIS

    LORIS is the system you use to register for courses. To log in: 

    1. Go to LORIS. 
    2. Enter your Laurier credentials. 

    If you receive errors in LORIS during registration, refer to the LORIS page. 

    If you lock your account, wait five minutes for it to reset. If you continue to have issues, contact the ICT Service Desk. 

    Be mindful of the academic dates found in the undergraduate calendar in relation to all course changes in LORIS.

    Registration Process

    Add Courses

    You must register for both fall and winter terms, but begin with your fall term courses first. To add courses during registration:

    1. From the main menu in LORIS: select Student Services > Click Open Registration Dashboard on the Registration and Class Schedule card > select Register for Classes.
    2. Select your term and click Continue.
    3. Select the Enter CRNs tab.
    4. Select + Add Another CRN until you have enough textboxes for your whole term.
    5. Type each CRN that you noted in step 3 into a box (for example: 1636). 
    6. Select Add to Summary to add all your courses.
    7. Press Submit on the summary page to officially register in your courses.

    Registered beside each lecture, lab and tutorial means you've successfully registered.

    If you need to drop any courses during the process: 

    1. From the main menu in LORIS: select Student Services > Click Open Registration Dashboard on the Registration and Class Schedule card > select Register for Classes.
    2. Select your term and select Continue. 
    3. Navigate to Summary section (bottom right of screen). 
    4. Select Drop Course from the Action dropdown fields, next to the course you wish to remove. 
    5. Select Submit.

    If a course you want to register in is full, you have the following options:

    • Add your name to the waitlist (if one is available).
    • Check LORIS regularly to see if new course sections are available. Sometimes Laurier may increase class sizes or add new course sections to accommodate the increase in demand.

    To view your weekly schedule:

    1. Log in to LORIS.
    2. From the main menu, select Student Services
    3. Click Open Registration Dashboard on the Registration and Class Schedule card
    4. Select View Registration Information.

    Virtual Asynchronous courses do not appear in your weekly schedule.

    Adjusting Lab and Tutorial Schedules

    You can switch a tutorial or lab section on LORIS without automatically dropping the lecture. For example: You are currently registered in SP101 Section A, Tutorial 1 but want to switch into Tutorial 2.

    Follow these steps to switch, provided there is room in the tutorial and there are no time conflicts.

    1. Log in to LORIS.
    2. From the main menu, select Student Services
    3. Click Open Registration Dashboard on the Registration and Class Schedule card
    4. Select Register for Classes.
    5. Select term and Continue.
    6. Go to Find Classes and Search for the new section you want to add. Select Add and it will go to your Summary as Pending status.
    7. Under "Summary," find the section you want to drop and select Drop Course.
    8. Press Submit.

    Waitlists

    If you weren't able to secure a spot in a class you would like to take, adding your name to a waitlist may be a great option for you. Waitlists exist for some courses and allow you to "get in line" for the next available space that may become available. 

    View the Academic Calendar for all academic and related dates, including the deadline to add/drop courses each term. Note - students will be unable to add themselves to a waitlisted course after the last day to add a class each term. 

    Common LORIS errors you may see are ‘course load maximum’, ‘prerequisite not met’ and ‘year level restriction’. Before you add yourself to the waitlist, make sure you don't have any restrictions.

    To add yourself to a waitlist:

    1. Complete a search under "Find Classes" in Register for Classes.
    2. Review the "Class Seats" column for available space in the section and the waitlist.
    3. If the course is full and there is space available on the wait list, Select Add. The course will be added to your Summary with a "Pending" status.
    4. Press Submit.
      • You will get a "Registration Add Error" message to let you know the course is full, but a waitlist is available.
    5. Under "Summary," go to the course and select Waitlisted from the Action drop down menu.
    6. Press Submit.
    7. Status will appear as "Waitlisted" in Summary.

    To view your wait list position:

    1. Select the Schedule Detail tab on the left panel and view course details.
    2. Select the arrow beside the Course Title to expand the course details.

    If you're at the top of the waitlist, and a spot becomes available, you will receive an email to your mylaurier email advising you have 24 hours to add the course through LORIS. If you miss your 24-hour window, you will be removed from the waitlist and the next person on the waitlist will have the opportunity to add the course.

    1. Log in to LORIS.
    2. Under the "Summary," select Enrolled for the wait listed course from the Action drop down menu.
    3. Press Submit and your status will change to "Registered."

    If you are seeing an error, review the common LORIS errors.
