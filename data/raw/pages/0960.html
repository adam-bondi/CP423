    Wi-Fi

    Wi-Fi access at Laurier is through our eduroam network, which:

    • Provides secure access for members of the educational and research communities.
    • Allows you to securely access network services while visiting other member organizations using your Laurier login without making special arrangements.

    A list of participating eduroam institutions is available at eduroam.org. Canadian eduroam institutions are listed at CANARIE. You can also review the Trust Association Document filed with CANARIE’s Canadian Access Federation.

    How to Setup Eduroam

    Update as of Sept. 22, 2025: 
    Following our previous email communications about campus Wi-Fi, all devices must forget the eduroam network and reconnect using new configuration details due to a security certificate provider change.

     

    Setup eduroam in three easy steps!

    1. Navigate to https://cat.eduroam.org/ to download the installer for Wilfrid Laurier University
    2. Install the Configuration Assistant Tool (CAT) for MyLaurier.ca Users
    3. Connect to eduroam from the list of available networks

    Please note that some devices may require additional steps to install the configuration tool and setup Wi-Fi. For information relating to various operating systems, please use the guide below to setup Eduroam based on the type of device you have.

    1. Select setup_eduroam from your list of available networks in range. You will be directed to cat.eduroam.org.
    2. Select the blue Click here to download your eduroam® installer button to download your Eduroam installer.
    3. Select Wilfrid Laurier University as your institution.
    4. Select user group MyLaurier.ca Users (for students).
    5. Select the Download your eduroam® installer MS Windows 10/Windows 11 button.
    6. Open the downloaded installer package to proceed with the installation process. It will be in your downloads folder in File Explorer.
    7. Select Next and enter your mylaurier.ca email address and password. 
    8. Select Install. 
    9. Navigate to your list of available networks. 
    10. Select eduroam.
    11. Select the Connect automatically checkbox.

    Download the Eduroam Configuration Assistant (CAT) Profile:

    1. Select setup_eduroam from your list of networks.
    2. A captive window will pop up, close this window. 
    3. On Safari or Google Chrome, navigate to cat.eduroam.org
    4. Select Wilfrid Laurier University as your institution.
    5. Select user group MyLaurier.ca Users (for students).
    6. Select the Download your eduroam® installer MacOS button.

    Install the CAT Profile: 

    1. Go to your system preferences: 
      • Select the Apple menu
      • Select System Preferences
      • Select Profiles.
    2. Select eduroam® and then select Install to install the profile
    3. Enter your full mylaurier.ca email address and password
    4. Click Install and then Click Install again within the important notice prompt
    5. When prompted, enter your computer user name and password

    Connect to the Network: 

    1. In your System Preferences, select Network.
    2. Select Wi-Fi.
    3. Select eduroam from your list of available networks
    4. Your device should now be connected

    1. Open the Select a network menu.
    2. Choose setup_eduroam and on on your brower, navigate to https://cat.eduroam.org
    3. Select Wilfrid Laurier University from the list of available institutions.
    4. Select user group MyLaurier.ca Users (for students).
    5. Download the Chrome OS install file for Eduroam.
    6. After it has installed to your device, navigate to the URL in Google Chrome: chrome://network
    7. Scroll to the bottom of the window and upload that file to the Import ONC file
    8. Once you have uploaded that file, connect to Eduroam on your Chromebook.
    9. When prompted, enter in your full @mylaurier.ca email address and password.
    10. Your Chromebook should now be connected.

    Troubleshooting ONC File Upload Errors

    If you can encounter an error like "error occured during ONC parsing", follow these steps: 

    1. Go to the list of available Wi-Fi networks at the bottom right corner
    2. Click on Eduroam 
    3. In the domain section, type wlu.ca
    4. In the identity section, enter your full @mylaurier.ca or @wlu.ca email address. 
    5. Enter your password. 
    6. You should be successfully connected.

    Frequently Asked Questions

    • When you move out of range your connection will drop.
    • When you move into range of another WAP you may not be able to connect. This occurs because some devices do not “release” their prior connection and will still try to connect to the previous WAP, even though a connection is no longer possible.
    • There are two ways to re-establish your Wi-Fi connection:
      • Reboot your device.
      • “Forget” or remove the old network connection.

    Wireless printers and game consoles will not connect on our network as we require WPA2 Enterprise security. No consumer grade printers and none of the current game consoles offer this level of security.

    Most residence dorm rooms and apartment styles now offer live hard-wired connections that will allow you to connect your consoles and IOT devices using a standard ethernet cable.

    To remove your device from a Wi-Fi connection on:  

    Windows 10

    1. Go to Start. 
    2. Select Settings, then Network and Internet.
    3. Select Wi-Fi.
    4. Click Manage Wi-Fi Settings.
    5. Under “Manage Known Networks,” select the network you want to be removed.
    6. Click Forget.

    Mac OS

    1. Go to System Preferences.
    2. Select Network.
    3. Select Wi-Fi on the left.
    4. Select the wireless network from the list.
    5. Select Disconnect.
    6. Select Advanced.
    7. Select the wireless network from the list.
    8. Click the "-" button to remove it from the list.
    9. Click OK.
    10. Click Apply.

    iOS

    1. Select Settings.
    2. Select Wi-Fi.
    3. When you select eduroam, you will be prompted for the password.
    4. Choose Cancel and then open the eduroam network (click on the blue arrow).
    5. Choose Forget this Network.
    6. Choose Forget.

    Android

    1. Go to Settings.
    2. Select Wireless and Networks.
    3. Select Wi-Fi Settings.
    4. Long press the network named eduroam.
    5. Select Forget Network.
